# RoboWebBuilderAnimeation
A free Chrome extension where a swarm of robots flies in and rebuilds every website you open, tile by tile, then flies away. Skippable, runs once a day per site, skips banking and login pages. 100% offline: no server, no account, no tracking. Works in Chrome, Edge and Brave

# how to use extenstion: 

Add files via upload
1. Download the ZIP file.
2. Right-click the ZIP and select Extract All.
3. Open Google Chrome.
4. Enter "chrome://extensions" in the address bar.
5. Enable Developer mode.
6. Click Load unpacked.
7. Select the extracted extension folder robobuilder
8. Your extension will now appear in Chrome.
